The port, five ways

The shipped Manifest row, with only the port changing between tabs. Today it is :8443, set in the same dim grey as tcp and reality and reading as one more transport token — when it is actually one of the two or three facts an operator opens this page for.

All five carry the three shapes a port really takes here: one port, two (OpenVPN can listen on separate TCP and UDP), and none at all (GRE is IP protocol 47). A treatment that only looks right on the first one is not finished.
