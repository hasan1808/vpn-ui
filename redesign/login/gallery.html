[VPN-UI] Theme Width

Five login directions

The Overview shipped on the bento direction. The login page never got redesigned with it, so it is still the old teal wave header with hardcoded colours that predate the token system entirely.

All five below are built on the panel's real tokens from web/assets/css/tokens.css, use no webfont (the panel is offline), and design every state the real page has: the conditional 2FA field, loading, wrong credentials, expired session, and the theme and language controls. Each preview is live. Click into it, toggle its states, switch its theme, try RTL.

Pick one and I will port it into web/html/login.html.

  • Gateway
  • Console
  • Tunnel
  • Aurora
  • Keyplate

Gateway

The login screen is the first tile of the dashboard.

Built from the same bento vocabulary the Overview already ships: surface fill, hairline stroke, uppercase eyebrow labels. The form takes the dominant tile. The satellites carry only what an unauthenticated page may honestly state, so the System Status tile is drawn as an empty scaffold that says "Available after you log in" instead of inventing telemetry to fill itself.

  • Theme and language promoted out of the gear popover into their own tile
  • Connection tile reuses the real TLS warning copy
  • Tiles settle into place once on load, then hold still

Console

Authenticating is a command, not a form.

Terminal chrome, monospace throughout, and the credential rows rendered as prompt lines. The voice is lifted from this project's own installer: the bold blue :: step header and the -> action arrow that deploy.sh already prints into a root shell. Errors read as command output rather than as a toast.

  • A live block caret, stopped under reduced motion
  • Prompt is an isolated LTR island so Persian and Arabic do not mangle it
  • Type sized to stay legible in mono on a phone

Tunnel

Show the thing the product actually does.

A slow canvas field of traffic crossing an encrypted segment, teal into blue, running behind a quiet high-contrast plate. The graphic is abstract atmosphere and is never labelled as live data. It is the one loud element, so everything else stays precise and silent.

  • Legibility over the animation is solved by the plate, not left to chance
  • Loop cancels under reduced motion and pauses on a hidden tab
  • The dimmest of the five by design. Judge it at full size

Aurora

The refined one, extending the direction you already liked.

A single plate floating in a broad, slow teal field, continuing the aurora treatment picked for VPN Services. Elevation comes from the panel's hairline border convention rather than a drop shadow, and the palette stays teal and slate. With this little furniture on the page, the Hello / Welcome line and the small print carry the whole hierarchy.

  • Deliberately not the purple-gradient glass card that every generated login is
  • backdrop-filter degrades to a solid plate that still holds contrast
  • Version and build sit in a footer rule inside the plate

Keyplate

Maximum restraint. The login disappears and the product speaks.

Near-empty canvas, underline-ruled fields, one vertical hairline that sets an asymmetric column instead of centring everything. No card. The wordmark is the largest element on the page and is set with real tracking. This is the option that wins on precision rather than on any added element.

  • Language and theme sit on the baseline, out of the way but not hidden
  • Field labels are real labels, not placeholders pretending
  • 2FA field appears without shifting the wordmark
Mockups only. Nothing under web/ has been changed for the login page. The files live in redesign/login/ next to the seven dashboard directions.
