Overview layout editor

Pick a tile, then drag a rectangle on the grid to place it. Each tile must stay a rectangle, which is what CSS grid-template-areas requires, so painting enforces it for you. Switch breakpoints with the buttons; each one is edited and emitted separately. When it looks right, copy the CSS at the bottom into web/assets/css/components.css, replacing the .bo-bento block.
